# Snake | Pygame

A Snake game made with Python and pygame, with animated snake heads, a speed slider, a saved high score, and a few surprises.

## Controls
- **W A S D** or **arrow keys**: move
- **P** or **Esc**: pause
- **Space** or **Enter**: start from the menu

## Run it
```
pip install pygame gif_pygame screeninfo
python Maingame/yourfile.py
```
Run it from the repo root so the `Assets` folder is found.

Or download `Snake.exe` from the Releases page (Windows only).
